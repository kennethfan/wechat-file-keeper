微清 WeClean — Mac 微信文件清理工具交互说明文档

版本：v2.0 ｜ 更新日期：2026-10-29 ｜ 配套产物：微信文件清理工具-UI交互原型.html

视觉基调：与「净盘 CleanDisk」同产品家族（浅色 macOS 原生风），主色为微信绿 #07c160

本版核心变化：信息架构基于微信 4.x 实测存储结构重构，废弃 v1.0 的"纯按会话"假设

一、产品定位与设计原则

产品定位：macOS 微信（4.x）媒体文件清理工具。与通用磁盘清理的差异点：微信数据有独立目录结构与"聊天记录不可触碰"的红线。

五条安全交互原则（贯穿全部流程）：

  1. 只读体检 — 分析阶段不改动任何文件，UI 常驻提示
  2. 不碰聊天记录 — db_storage（msg_*.db 数据库）在体检中单独列出、标记 ⛔ 禁止触碰、明确排除在扫描范围外；所有清理动作均声明"聊天记录不受影响"
  3. 废纸篓语义 — 清理 = 移入废纸篓，30 天内可恢复；完成页如实说明不立即释放磁盘
  4. 保护名单 — 星标会话完全免疫清理，防误删重要联系人的媒体
  5. 时间阈值锁定 — 阈值内的近期文件灰显上锁（🔒），从数据源头避免"刚发的文件被清掉"

二、实测存储结构依据（设计的事实基础）

微信 4.x（macOS）实际路径：~/Library/Containers/com.tencent.xinWeChat/Data/Documents/xwechat_files/<wxid>/

目录实测占用组织方式工具策略
msg/attach/2.0 GB会话哈希 → 月份 → Img按会话（进阶）视图，仅图片可直接定位
msg/video/1.8 GB月份平铺（2023-11/<md5>.mp4 + _thumb.jpg）按月份（主轴）
msg/file/145 MB月份平铺，保留原始文件名按月份（主轴）
cache / temp / business~220 MB杂项缓存孤儿与缓存，安全清
db_storage/545 MB聊天记录数据库（msg_*.db）⛔ 禁止触碰

关键结论（决定 IA）：微信 3.x 的 MessageTemp 纯会话组织已废弃；4.x 中视频/文件是全局按月池，归属会话需只读查询数据库（结构未公开）。因此主轴从"按会话"改为"按月份 + 孤儿/缓存"，按会话降级为进阶能力并在 UI 如实标注。

三、信息架构

窗口（macOS 红绿灯标题栏「微清 WeClean — 微信 4.x 文件清理」）
├── 侧边栏
│   ├── 微信数据卡（头像 + 路径 wxid 摘要 + 体检后显示占用/可清理）
│   ├── 清理
│   │   ├── 数据体检（概览，默认）
│   │   ├── 按月份清理（主轴，角标 = 有可清理项的月份数）
│   │   └── 孤儿与缓存（角标 = 孤儿文件数 + 缓存项数）
│   ├── 进阶
│   │   └── 按会话（图片）（角标 = 有可清理图片的会话数）
│   └── 安全
│       ├── 保护名单（角标 = 保护会话数）
│       └── 安全承诺（只读体检 / 不碰聊天记录 / 废纸篓 / ⛔ db_storage）
└── 主内容区（7 个视图态）
    ├── 数据体检 / 体检扫描（流程态）
    ├── 按月份清理（筛选 + 排序 + 分组/平铺开关）
    ├── 孤儿与缓存
    ├── 按会话（图片）（进阶）
    ├── 保护名单
    └── 清理进度 → 完成（流程态）
└── 全局层：微信运行横幅（main 顶部常驻）、确认弹窗、toast

导航守卫：未体检前点击清理类导航 → toast「请先完成数据体检」，不放行。

四、微信运行横幅（全局）

  • 默认显示：🟡 脉冲圆点 +「检测到微信正在运行，部分媒体文件可能被占用。建议先退出微信再清理」
  • 两个出口：
  • 「已退出微信」→ 横幅变暗、圆点变绿静止、文案改为确认状态
  • 「继续清理缓存（安全）」→ 变暗，文案说明将跳过可能被占用的近期文件
  • 位置固定在主区顶部，所有视图可见

五、数据体检（概览）

未体检态：

  • 环形图灰色，中心「—」；目录条形图全为占位「—」
  • 提示真实路径：~/Library/Containers/com.tencent.xinWeChat/Data/Documents/xwechat_files/<wxid>/
  • 主操作：「✨ 开始体检」+「只读分析 · 不改动任何文件 · 约 3 秒」

体检中：

  • 绿色进度环 + 百分比；滚动显示真实相对路径（msg/attach/<hash>/2024-08/Img… → msg/video/… → msg/file/… → cache/… → 检测孤儿缩略图… → （跳过 db_storage 聊天数据库））
  • 明示 db_storage 不在扫描范围内；提供「取消」

体检完成：

  • 环形图按 attach/video/file/cache 四色分段
  • 目录条形图：四个目录（含组织方式说明）+ 第五行 ⛔ db_storage 聊天数据库（红色、填充为 0，仅展示体积——"列出但禁止"的视觉语言）
  • 三张入口瓦片：按月份清理（主轴·占用合计）、孤儿与缓存（零风险合计）、按会话（进阶·attach 占用）；点击直达
  • 侧边栏微信卡更新为「媒体 X · 缓存 Y」；toast 汇报体检结论
  • 自动跳转按月份清理页

六、按月份清理（主轴视图，交互最重）

6.1 工具栏（两层）

第一层：筛选 + 视图 + 排序

  • 类型筛选 chips：全部 / 🖼 图片 / 🎬 视频 / 📄 文件
  • 大小门槛 chips：全部大小 / ≥10MB / ≥100MB
  • 「按月份分组」开关（iOS 风格，40×24 滑块，微信绿激活态）：
  • 开 = 分组模式（月份桶卡片）；关 = 平铺模式（跨月份统一列表）
  • 整行可点——点开关本体或点旁边文字均可切换（单点绑定，无双触发）
  • 文字动态提示当前模式：开=「按月份分组」，关=「平铺列表」，任何时候模式有文字可读
  • role="switch" + aria-checked，Space/Enter 键盘可切
  • 联动显隐：开→显示「月份排序」下拉；关→隐藏之、显示「☑ 选本页可清理项」按钮
  • 月份排序下拉（仅分组模式）：新→旧（默认）/ 旧→新 / 占用大→小
  • 文件排序下拉（两种模式通用）：大小 双向 / 时间 双向 / 名称 A→Z

第二层：时间阈值

  • 分段控件：30 天前 / 90 天前 / 180 天前（默认）/ 全部
  • 文案随档位变化（如「仅清理 180 天前的文件，近期文件已自动上锁保护」；选「全部」时警示"含近期，请谨慎"）

三层过滤叠加关系：实际可见且可清理 = 类型筛选 ∩ 大小门槛 ∩ 时间阈值 ∩ 非孤儿 ∩ 非已清理 ∩ 非保护会话（attach）

切换筛选/阈值会清空已勾选项——有意为之，防止用户清理"当前看不见"的文件。

6.2 分组模式（月份桶卡片）

  • 每个月份桶一张卡片：📅 头像 + 月份名 +「月份桶」标签；描述行显示各类型数量 + 可清理数；右侧合计大小与文件数
  • 点击头部展开：类型 tab（图片/视频/文件，带数量，随筛选收敛为单 tab）+「☐ 选本类可清理项」
  • 文件网格：缩略图卡（类型图标渐变底）+ 完整相对路径（如 2024-08/91c6524f….mp4）+ 大小 + N 天前
  • 可清理：正常态，点击勾选（圆勾变绿）
  • 阈值内：灰显 + 🔒「近期」角标，不可点
  • 已清理：🗑 图标灰显
  • 空月份桶自动隐藏；全部为空时显示「当前筛选与阈值下暂无可清理月份」

6.3 平铺模式（跨月份列表）

  • 单一列表，每行：复选框｜类型图标｜完整路径｜月份标签（蓝 tag）+ 来源会话（全局池）+ 天数｜大小
  • 与分组模式共享勾选状态（同一 key 空间）与文件排序；「选本页可清理项」一键全选当前筛选下所有可清理项

6.4 底部汇总栏

  • 勾选后毛玻璃滑出：合计大小（大字）+「已选 N 个文件 · 涉及 M 个月份桶」
  • 「取消选择」「🗑 安全清理」（未选时禁用）

七、孤儿与缓存

  • 顶部说明卡：「孤儿文件 = 无法再被微信引用的残留（如只有缩略图没有视频本体、聊天删除后遗留的哈希目录），清理零风险；缓存清理后微信按需重新下载」
  • 孤儿文件卡（有孤儿时显示）：橙色 🧩 头像 +「零风险」标签，文件网格带橙色「孤儿」角标
  • 安全缓存卡：Caches 资源缓存 / business 小程序与插件 / temp 临时文件，每项含路径 code + 用途说明 +「可再生成」标签
  • 底部汇总栏：「已选 N 项（孤儿 X · 缓存 Y）」+「🗑 移入废纸篓」

八、按会话（图片）—— 进阶视图

  • 顶部 caveat 横幅（能力边界如实告知）：微信 4.x 仅 msg/attach 图片按会话哈希组织可直接定位；视频/文件归属需只读查询微信数据库（结构未公开、涉隐私）。本视图仅覆盖图片类。
  • 会话卡片：头像（映射成功显示昵称首字，未识别显示「?」）+ 名称或 061d80f4…（未识别） + 哈希摘要 code + 双数字（可清理/总占用）
  • 星标 ☆：加入/移出保护名单（联动保护名单页与全部视图的过滤）
  • 受保护会话：卡片降透明度 +「🛡 已保护」标签，展开后显示保护说明、无文件网格
  • 未识别哈希：不假装知道是谁，如实显示哈希前缀 +「（未识别）」

九、保护名单

  • 说明卡：保护会话的图片完全免疫清理；「按月份清理」是全局时间维度不受会话保护影响——保留某月文件请用时间阈值（两种维度边界明确）
  • 名单行：头像 + 会话名 + 类型 + 图片占用 +「移出保护」
  • 空态引导：「在按会话（图片）中点击 ☆ 即可加入」

十、确认弹窗

  • 触发：按月份/按会话/孤儿与缓存 三个视图各自的清理按钮
  • 内容：⚠️ 图标 +「确认清理这些微信文件？」+ 副标题（共 N 项 · 合计 X · 按月份/会话/孤儿分组明细）+ 绿色信任行「移入废纸篓 · 聊天记录不受影响 · 30 天内可恢复」
  • 「取消」/「移入废纸篓」；Esc 与点击遮罩可关闭

十一、清理进度与完成

  • 进度：绿色渐变进度条 + 逐项清单（完成项点亮 ✓，文件名由灰变黑）
  • 完成：✓ 弹跳图标 + 大字「+X GB」+ 说明「聊天记录（db_storage）不受影响；如微信在运行建议重启释放内部缓存」
  • 「↩︎ 撤销本次清理」（放回全部文件，各视图恢复原状 + toast）｜「查看体检结果」

十二、全局交互规范

维度规范
反馈增删改均有 toast（顶部滑入，2.6s 消失）；导航守卫也走 toast
键盘全部勾选/卡片/开关支持 Tab + Space/Enter；Esc 关弹窗
无障碍role="checkbox"/"switch"/"dialog" + aria-checked/aria-modal；开关与图标按钮带 aria-label
动效统一 180ms；视图淡入上移；卡片悬停上浮；横幅圆点呼吸动画
数字容量/计数等宽字体（tabular-nums）；长文件名 RTL 方向技巧防路径前缀挤压
响应式≤760px 隐藏侧边栏

十三、核心状态流转

数据体检（未体检）
   │ 开始体检
   ▼
体检扫描 ──取消──▶ 数据体检
   │ 完成（自动进入按月份）
   ▼
按月份清理 ◀──导航──▶ 孤儿与缓存 / 按会话（图片）/ 保护名单
   │ 勾选 → 安全清理
   ▼
确认弹窗 ──取消──▶ 返回原视图
   │ 确认
   ▼
清理进度 ──完成──▶ 完成页 ──撤销──▶ 原视图（恢复）
                └─查看体检─▶ 数据体检（数字更新）

保护与阈值的作用域：会话保护只作用于 attach 图片；月份维度由时间阈值控制——两个维度边界在保护名单页明确说明。

十四、原型边界说明

  1. 文件清单为基于实测结构建模的演示数据（尺寸/月份对齐真实量级），非本机真实扫描结果
  2. 会话名映射在正式实现中需只读解析微信 SQLite（结构未公开）；原型用「已映射演示会话 + 未识别哈希」双色呈现
  3. 孤儿判定规则（缩略图无本体、哈希目录失效）在正式实现中需建立引用索引
  4. 清理仅更新视觉状态（灰显/移除），不真实删除；「继续清理缓存（安全）」模式未联动实际过滤逻辑（原型简化）
  5. 通配符、按类型全局聚合视图（v1.0 曾有）已按 4.x 结构取舍：类型维度并入月份桶 tab，不再单列
