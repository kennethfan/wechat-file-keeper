# 不做会话归属，不触碰加密数据库

微信把「谁在什么时候发了这个文件」存在 `db_storage/` 的加密 SQLite 里（543 MB）。要把它和 `msg/file` 里的路径对应起来，必须取得数据库密钥——密钥由微信在运行期持有，获取它意味着读进程内存、绕过微信自身的保护。

我们决定**不提供会话归属**：文件按类型、月份、大小组织，界面上明确告知「发送人信息受微信加密限制不可得」。图片缓存路径里的 32 位十六进制目录名只是会话指纹，同样不可反查。

这条边界同时挡住了两类风险：一是与微信的加密设计对抗，其稳定性完全不受我们控制，微信一次升级就可能失效；二是让工具可以保持纯本地、零网络请求、零额外权限。

## Consequences

- 用户无法回答「这个 PDF 是谁发的」，只能靠文件名与月份推断。
- 若将来微信官方提供导出接口，此决定应被重新审视。
